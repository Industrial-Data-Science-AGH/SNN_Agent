# Pochodzenie ilustracji

Tryb generowania: wbudowany image_gen. Referencje UI oraz stanowisko są obrazami generowanymi, nie wynikami eksperymentu. Makiety określają wygląd; normatywne zachowanie określa dokument architektury.

## Kierunki promptów

- Dashboard: ciemny SNN Lab, fioletowe płytki Lu.i odwzorowujące referencje użytkownika, przewody pobudzające i hamujące, LED potencjału i spike, panel neuronu po prawej, raster i zdarzenia na dole. Wersja v2 zatwierdzona wizualnie przez Wiktora.
- Lokalizacja v3: zachować układ v2 i osiem płytek N1–N8; wszystkie etykiety po angielsku; Network, Events, Experiments, Energy, Device; Live, Replay, Edit; Board count 0–50; Start, Pause view, Fit; DEMO • SAMPLE DATA. Pomiary przykładowe, kalibracja Unverified.
- Widok zdarzenia: ciemny interfejs tego samego systemu, angielskie etykiety, zdjęcie demonstracyjne, oś zdarzenia i wynik analizy; obecność osoby nie dowodzi braku uprawnień.
- Stanowisko: uporządkowany stół laboratoryjny, Raspberry Pi 5 w obudowie, Arduino Uno, MAX4466, kamera, LED, buzzer oraz oddzielna sieć Lu.i; monitor z angielskim dashboardem. Napis CONCEPT VISUALIZATION • NOT A WIRING DIAGRAM. Okablowanie poglądowe.

Fotografia Lu.i: giantaxon/lu.i-neuron-pcb, doc/figures/photograph-coin.jpg z repozytorium dostarczonego przez użytkownika. Licencja źródłowa w assets/LICENSE-Lui.txt.

Diagramy: opracowanie architektury; pliki DOT i SVG są edytowalnymi źródłami. Pliki PNG służą osadzaniu w dokumencie.
