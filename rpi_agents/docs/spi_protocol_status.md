# SPI Trigger Protocol Status

The SPI document describes the target protocol between the SNN trigger layer and

the host, for example Raspberry Pi. The current Arduino sketch in
`../encoder/snn_encoder/snn_encoder.ino` does not send those frames yet; it
emits single GPIO voltage spikes on pin `D2`.

The planned packet is consistent with `SAMPLE_PERIOD_MS`, `SPI_MAGIC_BITS`, and
`SPI_PACKET_SIZE` generated by `snn_pipeline/export.py`.

## Planned Packet

The packet is 2 bytes and is intended to be sent every 10 ms, about 100 Hz.

```text
byte 0:
  bit 7..5: magic number 0b101
  bit 4:    trigger flag
  bit 3:    N1 fired
  bit 2:    N2 fired
  bit 1:    N3 fired
  bit 0:    reserved, e.g. inhibitor status

byte 1:
  bit 7..0: timestamp LSB
```

Examples:

```text
idle:  0xA0 0xXX
alarm: 0xA8 0x3F
```

Firmware work remains to bridge the current GPIO prototype to this packet.
